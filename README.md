# Java — Estudos e Exercícios

Repositório dedicado aos meus estudos e exercícios práticos durante minha jornada de aprendizado da linguagem Java.

## Sobre o repositório

Aqui estão reunidos exercícios desenvolvidos ao longo do meu curso de Java, com o objetivo de fortalecer minha lógica de programação, desenvolver meu raciocínio computacional e consolidar meus conhecimentos na linguagem.

Cada exercício está organizado em sua própria pasta, com um nome que representa sua finalidade.

## Conteúdos praticados

- Variáveis e tipos de dados
- Entrada e saída de dados
- Operadores matemáticos e lógicos
- Estruturas condicionais (`if`, `else if`, `else`)
- Estruturas de repetição (`for`, `while`, `do-while`)
- Operações matemáticas e cálculos
- Contadores e acumuladores
- Manipulação de dados com `Scanner`
- Formatação de saídas com `printf`

## Tecnologias e ferramentas

- Java
- IntelliJ IDEA
- Git
- GitHub

## Objetivo

Construir uma base sólida em Java, aprimorar minhas habilidades de programação e evoluir continuamente para atuar profissionalmente como desenvolvedor de software.

## Evolução dos estudos

Este repositório será atualizado conforme avanço no curso e desenvolvo novos exercícios e projetos.
